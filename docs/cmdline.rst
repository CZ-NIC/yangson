.. _cmdline-tools:

==================
Command-line tools
==================

This section describes two command line tools that are part of the Yangson package. A few more specialized Python scripts are available in the project repository, directory `tools/python`_.

.. _yangson-tool:

yangson
-------

This tool provides several commands that make essential high-level functions of the Yangson library acessible from the command line. They are:

``tree``
    Printing a schema tree tree diagram, see :meth:`.DataModel.ascii_tree`.

``schema-id``
    Print an opaque identifier of the YANG module set, see
    :meth:`.DataModel.module_set_id`.

``digest``
    Print the schema digest in JSON format, see
    :meth:`.DataModel.schema_digest`.

``validate``
    Validate an instance document against a data model schema or subschema,
    see :meth:`.InstanceNode.validate`.

``dump``
    Dump the YANG data model object to a file in a serialized (pickled)
    form, see the Python's standard library module :mod:`pickle`. This may
    significantly shorten loading time compared to repeated parsing of
    source YANG modules, especially for large data models.

For example, a tree diagram of the schema from :ref:`sec-ex4` can be
generated by executing the following command in the
``docs/examples/ex4`` directory:

.. shtest::
   :cwd: examples/ex4

   $ yangson yang-library-ex4.json -p .:../../../yang-modules/ietf tree
   +--rw example-4-a:bag!
   |  +--ro bar <boolean>
   |  x--rw foo <uint8>
   |  +--rw (opts)?
   |     +--:(a)
   |     |  +--rw baz? <empty>
   |     +--:(example-4-b:fooref)
   |        +--rw fooref? <leafref>
   +--rw example-4-b:quux# <decimal64>

An overview of command-line parameters can be obtained by using the ``--help/-h`` switch:

.. sh:: yangson --help

For each of the commands listed above, an overview of its syntax can be obtained by putting the ``--help/-h`` switch **after** the command's keyword, for example

.. sh:: yangson yang-library.json tree --help

Consult the :ref:`manual page <yangson-man>` for further details. Autocompletion scripts for popular Unix shells are also part of the *Yangson* distribution.

.. _convert8525-tool:

convert8525
-----------

This script allows for extracting one schema from NMDA-enabled YANG
library data [RFC8525]_ (in JSON representation) and storing its
parameters in the old YANG library format of [RFC7895]_ that can be
used as input to *Yangson* library functions and the *yangson* tool.

As an example, the distribution directory ``docs/examples/ex3`` also contains new-format YANG library data in the file ``rfc8525-ex3.json``. It can be converted to the old format by executing the following command in that directory:

.. shtest::
   :cwd: examples/ex3

   $ convert8525 --path ../../../yang-modules/ietf --datastore running rfc8525-ex3.json

       "module": [

           "conformance-type": "implement",
           "namespace": "http://example.com/example-3/a",
           "submodule": [
             {
               "name": "example-3-suba",
               "revision": "2017-08-01"
             }
           ],
           "feature": [
             "fea1",
             "fea2"

         },
         {
           "name": "example-3-b",

An overview of command-line parameters can be obtained by using the ``--help/-h`` switch:

.. sh:: convert8525 --help

Consult the :ref:`manual page <convert8525-man>` for further details.
